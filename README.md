# crossstitch_designer
CrossStitch Designer — Convert any image into a printable cross-stitch pattern with DMC thread color matching. Available as a standalone desktop app (Python/PySide6) and a single-file web app. Features CIEDE2000 perceptual color matching, KMeans clustering, background removal, zoomable pattern viewer, and PDF/PNG/CSV export.

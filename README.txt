SINGLE-FILE WEB APP
───────────────────
  crossstitch_designer.html  is 100% self-contained.
  Open it in any modern browser — no install, no server needed.

QUICK START
───────────
  1. Open crossstitch_designer.html in Chrome, Firefox, Edge or Safari
  2. Click  📂 Load Image  (or drag & drop)
  3. Adjust grid size and number of colors in the left panel
  4. Pick background color if needed (Color Tolerance method)
  5. Click  ⚙ Analyse
  6. View pattern in the centre, legend on the right
  7. Export as PDF, PNG, JPEG or CSV shopping list

EXPORT
──────
  PNG / JPEG  — full-res chart with symbols, grid, legend panel
  PDF         — auto-tiled, printable, cover + pattern + legend + shopping list
  CSV         — shopping list: DMC number, name, skeins needed

BACKGROUND REMOVAL
──────────────────
  Color Tolerance (default)
    ① Set method to "Color Tolerance" in the left panel
    ② Click "Pick Background Color"
    ③ Click on the background area of your image
    ④ Adjust tolerance slider (higher = removes more similar shades)
    ⑤ Enable "Corner flood-fill" for cleaner edges

  AI (auto-download ~50 MB)
    ① Set method to "AI (auto-download)"
    ② The library downloads on first use — internet required
    ③ Works best on photos with a clear subject

COLOR REMAPPING
───────────────
  Click any DMC number in the legend (right panel) to open the
  remap dialog and swap that color for any other DMC thread.

HOSTING ON GOOGLE SITES
────────────────────────
  Google Sites does NOT allow uploading arbitrary HTML.
  Use one of these free hosting options instead, then embed:

  Option A — GitHub Pages (recommended, free):
    1. Create a free account at github.com
    2. New repository → upload crossstitch_designer.html
    3. Settings → Pages → Branch: main, folder: / (root) → Save
    4. Your URL: https://<user>.github.io/<repo>/crossstitch_designer.html
    5. In Google Sites: Insert → Embed → URL → paste the GitHub Pages URL

  Option B — Netlify Drop (fastest, free):
    1. Go to netlify.com/drop
    2. Drag crossstitch_designer.html onto the page
    3. Copy the generated URL
    4. Paste in Google Sites: Insert → Embed → URL

  Option C — Google Drive (simplest):
    1. Upload crossstitch_designer.html to Google Drive
    2. Right-click → Share → Anyone with the link → Viewer
    3. Get shareable link
    Note: Google Drive HTML preview may restrict JS; Netlify/GitHub are better.

EMBED SIZE IN GOOGLE SITES
──────────────────────────
  Recommended embed dimensions: 1400 × 850 px minimum.
  In Google Sites, after inserting the embed, resize it by
  dragging the handles to fill the page width.

BROWSER COMPATIBILITY
─────────────────────
  Chrome 90+, Firefox 88+, Edge 90+, Safari 15+
  Mobile: works but desktop is strongly recommended
  (the pattern canvas needs space for zoom/pan)

DMC THREAD SYSTEM
─────────────────
  483 DMC colors embedded with CIEDE2000 perceptual matching.
  Stitch estimates assume 2-strand full cross-stitch on Aida.
  1 skein = 8 m = 800 cm; 5 cm thread per stitch × 2 strands.
